# Split the cookie store into shops where they are used (much later)

**Dev (2026-10-30):** "the overall cookie store would be spread into areas on the main game screen, or even in one of the minigames. The cookie store would be renamed to baking store, and would be placed after the baking slot manager. The ticket store would be housed in the lottery game, and the boost store would be located in the main game screen, but after the boost slot manager. ... for much much later." Added to the todo list as Unfinished. Not planned.

## Thoughts given to the dev

- Good fit: each shop sits next to what it feeds (tickets beside scratching, boosts beside the boost slot manager, upgrades beside the slots), fewer menu levels, and the cookie store stops being a grab bag.
- Best done AFTER [[project_shop_pack_menus_plan]], so the shops are moved once in their final form.

## Open questions for when it is planned

- Where selling cookies lives (likely the baking store, since it is the money source for upgrades).
- Keyboard shortcuts: Alt S opens the cookie store today; new shortcuts for the moved shops (boost shop near Alt N?).
- Rank gates move with the shops (tickets already gated with the lottery at rank 30; boosts at 110).
- Whether singles and bundles stay together in the baking store.
- A big readme rework (cookie store section, getting started, keyboard commands) and probably several changelog entries; players' habits change, so the changelog should explain where each shop went.
