# Rank burst plan (7.1)

Covers four todo items as one batch (dev, 2026-10-25): all ranks at once + summary message; consistent milestone announcements; rewards taking money past ~rank 21 million; announcements/milestones stopping past ~rank 2 billion. Background and examples: code #11, #9, #31 and the Duplication hotspots rank-up entry in [[project_bugs_code]]. Build one section per turn, wait for the dev to test and commit between sections ([[feedback_stage_commits_before_big_changes]], [[feedback_pause_after_each_fix]]); docs last ([[feedback_docks_last]]). Re-locate code by symbol.

## Locked decisions

- **One rank-up function.** Today the rank-up block exists twice: `clickergame()` in `game.nvgt` and `check_rank()` in `ranks_table.nvgt` (called by every minigame). Merge into `check_rank()`; `clickergame()` calls it.
- **Milestones use the main-screen rule everywhere (dev chose):** baking mode off → `dlg_buffer(msg, "critical")` (a dialog); baking mode on → `speak_buffer(msg, "critical")`. Applies in minigames too (they always spoke before). Every crossed milestone still fires its own reward, unlock sound and message — dev is fine with several dialogs in a row (Enter/Space/A skip, holding A skips them all). Don't combine them.
- **Every earned rank in one pass:** `while (cookieXP >= xprequired)`. Final rank and every reward are the same as before; only the timing changes. Example at default mods: 1 billion XP from rank 1 → rank 15,812 instantly instead of ~1.5–3 minutes.
- **Thinning applied once per pass:** keep the rule (every rank to 9, every 10th to 90, …) but announce only the highest thinned rank crossed in the pass, with one set of sounds (`play_rank_sound` + `rankach`). Normal play (one rank per pass) is unchanged.
- **[summary] section in ranks.table (dev chose):** optional, one message line, tokens `%name%`, `%from%`, `%rank%`, `%ranks%`, `%amount%` (total of every default reward in the pass, formatted by the default reward's target: currency for coins). Used only when a pass gains more than one rank AND crosses at least one thinned rank; then it replaces the thinned default message. Sound: `play_rank_sound(total)` + one `rankach`. If `[summary]` is missing, fall back to the highest thinned rank's default message. Shipped text: "Wow, %name%! You climbed %ranks% ranks, from rank %from% to rank %rank%! You've earned a total of %amount% for your achievements. Great work!"
- **Overflow fixes use doubles, not int():**
  - Reward rolls: new helper rolling `minVal + floor(random_float() * (maxVal - minVal + 1))`, clamped to `[minVal, maxVal]`; `random_float()` is the engine's [0, 1) float ([[reference_legacy_nvgt_source]], `src/random.cpp`). Replace `random(int(minVal), int(maxVal))` in `apply_rank_reward` (ranks_table), baker events (`baker_events.nvgt`), the prestige default reward (`prestige_table.nvgt`), and the two lottery prize rolls (`lottery_table.nvgt`; leave the ×100 percent roll alone).
  - Rank checks: thinning modulo via `rank - rankstep * floor(rank / rankstep) == 0` instead of `int(rank) % int(rankstep)`; milestone match `double(rankRewards[i].rank) == rank`; ticket-shop locks in `menu.nvgt` compare `rank < min_rank` directly instead of `int(rank) < …` (past 2^31 `int(rank)` goes negative and would lock every ticket).
  - Prestige rank (dev moved it into this plan as section 3): `int rankReached` in `resetgame` (`cycrz.nvgt`), `prestige_run.rank_reached`, and `show_prestige_summary(int level, int rankReached, …)` become double; `readdata` reads `prestigeHistory_rank_<i>` with `read_double` instead of `read_int`. Old saves are safe: they stored it as an integer, and the engine's dictionary `Get(double&)` converts a stored int64 to double (Legacy-NVGT `ASAddon/src/scriptdictionary.cpp` ~776), so no migration is needed. Display via `format_number`.
- **Performance:** a 500,000-rank pass must not stall. Roll and apply each rank's reward, but build message strings only for the announced rank and the milestones. If testing still shows a pause, cap at ~10,000 ranks per pass.
